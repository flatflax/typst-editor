M18 — CJK IME composition spike

Standalone harness, no build step, no backend integration. Tests whether a self-drawn cursor/composition overlay over a real Typst-rendered SVG can host CJK IME composition acceptably. See plan.md / doc/phase3-single-view.md.

How to test
  1. Click anywhere on the rendered page below to place the caret and focus the hidden input.
  2. Switch your OS input method to Chinese (Pinyin), type a short phrase (e.g. "nihao"), watch the blue-underlined overlay and the event log. Confirm the candidate window appears near the caret.
  3. Repeat with Japanese (e.g. type "konnichiha" and use space/arrow keys to move between candidate segments before confirming) — watch whether segment boundaries are visible to the log at all.
  4. Repeat with Korean (e.g. type "ㄱ ㅏ ㄴ" via a Hangul layout) — watch whether the composition overlay updates by replacing the displayed block in place (간) rather than appending onto it.
  5. For each language: try Backspace mid-composition, and Escape mid-composition. Note in the log whether compositionend fires, and with what data.

This harness does not attempt exact glyph-accurate cursor placement (that's M20) — the caret/overlay position is a plain click-to-pt mapping onto the SVG's own coordinate space, good enough to judge whether the composition/candidate-window mechanism itself is viable at all.
